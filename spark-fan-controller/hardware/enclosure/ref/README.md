# Reference models

`nvidia_dgx_spark_printables_1512927.stl`: 1:1 NVIDIA DGX Spark by SchwickSchwimmer,
https://www.printables.com/model/1512927 (CC BY-NC-SA). Front panel texture not modelled (flat).

`upstream_dgx_fan_shroud.stl`, `upstream_shroud_leg.stl`: copies of `3D Files/Nvidia DGX Spark/DGX Fan Shroud.stl`
and `Shroud Leg.stl` from this repo (hyudryu/DGX-Spark-Fan-Shroud, MIT), so `full_assembly.scad` also works
outside the fork. The DGX Spark model above is CC BY-NC-SA and is not committed; download it from Printables
into this folder to see the box in the assembly views.
